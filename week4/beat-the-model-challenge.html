Beat the model challenge

Ten home games are coming up for Biscayne Bay FC and the Breakers. Read the facts and forecast the crowd, then see whether your judgment beats a simple model built from earlier games.

How to use this interactive
  1. Read the facts for each game: opponent, day, promotion, weather, and price.
  2. Set your attendance forecast with the slider or type a number.
  3. Lock it in to see the model forecast and the actual crowd.
  4. Within 5% of the actual crowd earns 10 points, within 10% earns 7, within 15% earns 4, otherwise 1.
  5. After ten games, see who forecast better and which factors mattered most.

What the model learned from earlier home games

The model is a simple average-based formula: start from a typical crowd, then add or subtract what each factor was worth in earlier home games. It ignores things it cannot see (a star player's return, a holiday weekend, a big local event, a viral promotion), which is where a manager's knowledge still matters.
